✨ Why Writers Love Snara

🔄 Automatic Structure

Write naturally in Markdown. Snara intelligently detects and organizes Acts → Chapters → Scenes → Beats.

📋 Live Table of Contents

Always up-to-date. Click any heading to jump instantly.

🧭 Kanban Board

Visual drag-and-drop planning for scenes, chapters, and arcs. Real-time sync with your manuscript.

🤖 Context-Aware AI Assistant

Chatbot + floating toolbar. Brainstorm, rewrite, summarize, change tone. Works with Groq, OpenAI, or any compatible provider.

📚 Multi-Book Support

Manage multiple novels or screenplays in one workspace.

📁 Files & Media Workspace

Import/export Markdown & HTML, media gallery, smart autocomplete, metadata (characters, locations, custom fields).

🧠 Customizable Preprompts for AI Agents

Supercharge brainstorming with ready-to-use (and fully editable) AI preprompts.
Edit json/preprompts.json — changes appear instantly in the toolbar & chatbot.

Default preprompts included (customize anytime):

[
    {
        "label": "Summarize",
        "value": "Act as an expert summarizer for a busy founder. Your Task: Create a concise, comprehensive, and factual summary of the provided text's main ideas. "
    },
    {
        "label": "Characters",
        "value": "Based on the text below, provide two sections: 1. A comma-separated list of individual character names. 2. A list of those same characters, each with a brief detail. Strictly exclude any plural groups or collective characters. Provide only the requested content without headers, introductions, or closing remarks."
    },
    {
        "label": "3 Act story structure",
        "value": "Transform the user's input into a vivid, detailed, and emotionally resonant narrative scene. This scene must strictly adhere to a 3-act story structure, bringing the core elements of the input to life through immersive description and authentic dialogue: "
    },
    {
        "label": "Professional",
        "value": "Reply in a formal, professional business tone: "
    },
    {
        "label": "Unfiltered Dialog",
        "value": "Create dialog that natural and common, with gesture and bodylanguage: "
    }
]

These appear directly in the AI toolbar and chatbot. Perfect for fast brainstorming, character work, plot structuring, and tone control.

🚀 Quick Start

  1. Clone the repo
    git clone https://github.com/tacoen/snara.git && cd snara
  2. Set permissions on /data/ and /json/ folders (web server must write to them).
  3. Run locally
    php -S localhost:8000
  4. Open http://localhost:8000 — Snara auto-creates everything on first run.

Test the AI instantly: bash test.sh (uses Groq + Llama 3.3 by default)
